# Security policy

## Reporting a vulnerability

After private vulnerability reporting is enabled on the public repository,
report vulnerabilities with a GitHub Security Advisory in
`aiaiohhh/vyben-runner`. Until that channel is enabled and independently
verified, email `hello@vyben.app` with the subject `SECURITY` and request secure
upload instructions. Do not open a public issue for a suspected secret leak,
token bypass, command injection, path traversal, repository permission escape,
artifact integrity failure, or branch-protection bypass.

Include the affected commit SHA, reproduction steps, expected impact, and any
suggested mitigation. Do not include real credentials, customer repository
content, or personal data in the report.

## Supported releases

Only immutable commit SHAs explicitly published by Vyben are supported. Mutable
branches and tags are not release channels.
